1. เกี่ยวกับเว็ปไซต์
เว็บไซต์นี้จัดทำขึ้นเพื่อให้ผู้ใช้สามารถสร้าง จัดเก็บ และจัดการแฟ้มสะสมผลงานของตนเองได้ โดยสามารถเพิ่มข้อมูลส่วนตัว                เพิ่มรายการผลงาน บันทึกข้อมูล และดูรายละเอียดของผลงานได้ นอกจากนี้เว็บไซต์ยังรองรับการบันทึกข้อมูลด้วย Local Storage เพื่อให้ข้อมูลยังคงอยู่เมื่อผู้ใช้กด Refresh
2. เว็บไซต์แฟ้มสะสมผลงาน
เว็บไซต์เผยแพร่ผ่าน GitHub Pages สามารถเข้าใช้งานได้ที่
https://saesuenghabes.github.io/teamproject/
3. ความสามารถของเว็บไซต์
-สามารถลบ Portfolio และ Portfolio Item ที่ไม่ต้องการได้
-รองรับ Light Mode และ Dark Mode
-รองรับการแสดงผลบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
4. วิธีเปิดใช้งานเว็บไซต์
4.1 เข้าใช้งานเว็ปไซต์ผ่าน Web Browser ได้โดยตรง โดยไม่จำเป็นต้องติดตั้งโปรแกรม
4.2 กดเข้าสู่หน้า “สร้าง Portfolio” ที่มุมบนขวามือ จากนั้นไปที่หัวข้อเพิ่ม Portfolio ใหม่ กรอกข้อมูลให้ครบถ้วนและถูกต้อง จากนั้นกด “บันทึก Portfolio”
4.3 จากนั้นไปที่หัวข้อเพิ่ม Portfolio Item ใหม่ กรอกข้อมูลให้ครบถ้วนและถูกต้อง จากนั้นกด “บันทึก Portfolio Item”                เพื่อเพิ่มผลงานลงใน Portfolio หากต้องการลบข้อมูลที่ตัวเองกรอกไปแล้ว กด “ล้างฟอร์ม” เพื่อลบข้อมูลที่เคยกรอกไปก่อนกดบันทึก
4.4 เมื่อสร้าง Portfolio และเพิ่ม Portfolio Item แล้วต้องการเรียกดูข้อมูลที่ตัวเองบันทึกไป ให้กดเข้าสู่หน้า “PORTFOLIO”               ที่มุมบนขวามือ จะเห็นข้อมูลที่ตัวเองเคยกรอกไป หากต้องการลบข้อมูลที่เคยกรอกและกดบันทึกไปแล้ว ให้กด “ลบ Portfolio”และ“ลบ Item”ตามหัวข้อที่ต้องการลบ
6. การจัดเก็บข้อมูล (Data Storage)
เว็บไซต์ใช้ Local Storage ในการจัดเก็บข้อมูล โดยข้อมูล Portfolio และ Portfolio Item จะถูกบันทึกลงใน Browser อัตโนมัติเมื่อมีการเพิ่มหรือแก้ไขข้อมูล เมื่อ Refresh เว็บไซต์บน Browser เดิม ระบบจะโหลดข้อมูลที่บันทึกไว้กลับมาแสดงผลโดยอัตโนมัติ
** หมายเหตุ: ข้อมูลถูกจัดเก็บภายใน Browser ของผู้ใช้แต่ละคน ไม่ใช่ฐานข้อมูลส่วนกลาง และการล้างข้อมูลเว็บไซต์หรือ Browser อาจทำให้ข้อมูลที่บันทึกไว้สูญหายได้ **
