# Team Project – Portfolio Website

## 1. เกี่ยวกับเว็บไซต์ (About Website)

เว็บไซต์นี้จัดทำขึ้นเพื่อให้ผู้ใช้สามารถสร้าง จัดเก็บ และจัดการแฟ้มสะสมผลงานของตนเองได้ โดยสามารถเพิ่มข้อมูลส่วนตัว เพิ่มรายการผลงาน บันทึกข้อมูล และดูรายละเอียดของผลงานได้ นอกจากนี้ เว็บไซต์ยังรองรับการบันทึกข้อมูลด้วย Local Storage เพื่อให้ข้อมูลยังคงอยู่แม้ผู้ใช้จะกด Refresh หน้าเว็บไซต์

## 2. เว็บไซต์แฟ้มสะสมผลงาน (Portfolio Website)

เว็บไซต์เผยแพร่ผ่าน GitHub Pages สามารถเข้าใช้งานได้ที่

[https://saesuenghabes.github.io/teamproject/](https://saesuenghabes.github.io/teamproject/)

## 3. ความสามารถของเว็บไซต์ (Features)

- สามารถเพิ่มและลบ Portfolio ได้
- สามารถเพิ่มและลบ Portfolio Item ได้
- รองรับ Light Mode และ Dark Mode
- รองรับการแสดงผลบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## 4. วิธีเปิดใช้งานเว็บไซต์ (How to Use)

**4.1** เข้าใช้งานเว็บไซต์ผ่าน Web Browser ได้โดยตรง โดยไม่จำเป็นต้องติดตั้งโปรแกรมเพิ่มเติม

**4.2** กดเข้าสู่หน้า "สร้าง Portfolio" ที่มุมบนขวามือ จากนั้นไปที่หัวข้อเพิ่ม Portfolio ใหม่ กรอกข้อมูลให้ครบถ้วนและถูกต้อง แล้วกด "บันทึก Portfolio"

**4.3** ไปที่หัวข้อเพิ่ม Portfolio Item ใหม่ กรอกข้อมูลให้ครบถ้วนและถูกต้อง จากนั้นกด "บันทึก Portfolio Item" เพื่อเพิ่มผลงานลงใน Portfolio หากต้องการล้างข้อมูลที่กรอกไว้ก่อนบันทึก สามารถกด "ล้างฟอร์ม" ได้

**4.4** เมื่อสร้าง Portfolio และเพิ่ม Portfolio Item เรียบร้อยแล้ว หากต้องการดูข้อมูลที่บันทึกไว้ ให้กดเข้าสู่หน้า "PORTFOLIO" ที่มุมบนขวามือ ระบบจะแสดงข้อมูลที่เคยบันทึกไว้ หากต้องการลบข้อมูลที่บันทึกแล้ว สามารถกด "ลบ Portfolio" หรือ "ลบ Item" ตามรายการที่ต้องการลบได้

## 5. การจัดเก็บข้อมูล (Data Storage)

เว็บไซต์ใช้ Local Storage ในการจัดเก็บข้อมูล โดยข้อมูล Portfolio และ Portfolio Item จะถูกบันทึกลงใน Browser โดยอัตโนมัติเมื่อมีการเพิ่มหรือแก้ไขข้อมูล เมื่อผู้ใช้ Refresh เว็บไซต์บน Browser เดิม ระบบจะโหลดข้อมูลที่บันทึกไว้กลับมาแสดงผลโดยอัตโนมัติ

**หมายเหตุ:** ข้อมูลถูกจัดเก็บภายใน Browser ของผู้ใช้แต่ละคน ไม่ใช่ฐานข้อมูลส่วนกลาง การล้างข้อมูลเว็บไซต์หรือข้อมูล Browser อาจทำให้ข้อมูลที่บันทึกไว้สูญหายได้
