# Team Project – Portfolio Website

## 1. เกี่ยวกับเว็บไซต์ (About Website)

เว็บไซต์นี้จัดทำขึ้นเพื่อเป็นพื้นที่สำหรับสร้างและจัดเก็บแฟ้มสะสมผลงาน (Portfolio) โดยผู้ใช้สามารถเพิ่มข้อมูลส่วนตัว สร้าง Portfolio และเพิ่มรายการผลงาน (Portfolio Item) นอกจากนี้ยังรองรับการ Import และ Export ข้อมูลในรูปแบบ JSON รวมถึงสามารถทดลองเล่นเกม Blackjack Challenge เพื่อสร้างไฟล์ Portfolio JSON ได้

## 2. วิธีติดตั้ง (Installation)

1. ดาวน์โหลดโปรเจกต์จาก GitHub Repository และ Clone โปรเจกต์ลงในเครื่อง
2. ติดตั้ง PHP เวอร์ชัน 8.0 ขึ้นไป
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์
4. จากนั้นตรวจสอบการติดตั้ง PHP ด้วยคำสั่ง

```bash
php -v
```

## 3. วิธีทดสอบระบบ (How to Test)

ผู้ใช้สามารถทดสอบการทำงานของเว็บไซต์ได้ตามขั้นตอนต่อไปนี้

**3.1 การสร้าง Portfolio**

1. เข้าไปที่หน้า Create Portfolio 
2. กรอกข้อมูลส่วนตัวให้ครบทุกช่อง
3. กดปุ่ม Save Portfolio (หากผู้ใช้กรอกข้อมูลผิด ระบบจะแจ้งเตือนและกลับไปยังส่วนที่ต้องการให้ผู้ใช้กรอกข้อมูลใหม่)
4. ตรวจสอบว่าระบบบันทึก Portfolio สำเร็จ

**3.2 การเพิ่ม Portfolio Item**

1. เลือก Portfolio ที่ต้องการเพิ่มผลงาน
2. กรอกข้อมูล Portfolio Item ให้ครบถ้วน
3. กดปุ่ม Save Portfolio Item
4. ตรวจสอบว่ารายการผลงานปรากฏใน Portfolio ที่เลือก

**3.3 การแก้ไขและลบข้อมูล**

1. เข้าไปที่หน้า Portfolio
2. ทดลองแก้ไขข้อมูล Portfolio Item
3. ทดลองลบ Portfolio Item
4. ทดลองลบ Portfolio
5. ตรวจสอบว่าข้อมูลเปลี่ยนแปลงตามที่ดำเนินการ

**3.4 การบันทึกข้อมูล**

1. สร้าง Portfolio และเพิ่ม Portfolio Item
2. Refresh หน้าเว็บไซต์
3. กลับไปดูข้อมูลใน Portfolio ว่าข้อมูลยังอยู่

**3.5 การ Import และ Export**

1. ทดลอง Export Portfolio หรือ Portfolio Item เป็นไฟล์ JSON
2. ทดลอง Import ไฟล์ JSON กลับเข้าสู่ระบบ
3. ตรวจสอบว่าข้อมูลที่นำเข้าแสดงผลถูกต้อง

**3.6 Blackjack Challenge**

1. เข้าไปที่หน้า Blackjack Challenge
2. กดเริ่มเกมและทดลองเล่น
3. เมื่อชนะ ให้กรอกชื่อ-นามสกุล
4. กดสร้างไฟล์ Portfolio JSON
5. ดาวน์โหลดไฟล์และตรวจสอบว่าไฟล์ถูกสร้างเรียบร้อย

## 4. วิธีการเล่นเกม Blackjack 21

**กติกาการเล่น**

ผู้เล่นจะแข่งขันทำแต้มกับบอท โดยพยายามทำผลรวมแต้มให้ใกล้เคียง 21 มากที่สุด หากผลรวมแต้มเกิน 21 จะถือว่าแพ้ทันที

**วิธีการเล่น**

1. กดจั่วไพ่เพื่อเพิ่มแต้ม
2. กดหยุดเมื่อพอใจกับแต้มของตนเอง
3. รอผลการแข่งขันกับบอท
4. เมื่อชนะเกม ให้กรอกชื่อ-นามสกุล
5. กดปุ่มสร้าง Portfolio JSON
6. ดาวน์โหลดไฟล์ Portfolio JSON เพื่อนำไป Import เข้าสู่ระบบ Portfolio

## 5. วิธีการ Import และ Export Portfolio Item

**5.1 การ Export Portfolio Item (ส่งออกข้อมูล)**

1. เข้าไปที่หน้า Portfolio ที่ต้องการ
2. เลือก Portfolio Item ที่ต้องการส่งออก
3. กดปุ่ม ส่งออก JSON
4. ระบบจะแสดงข้อมูล Portfolio Item ในรูปแบบ JSON
5. กดปุ่ม Download เพื่อดาวน์โหลดไฟล์ JSON เก็บไว้ในเครื่อง

**5.2 การ Import Portfolio Item (นำเข้าข้อมูล)**

1. เข้าไปที่หน้า Create Portfolio
2. เลือกไฟล์ JSON ที่ต้องการนำเข้า หรือวางข้อความ JSON ลงในช่อง Paste JSON
3. ตรวจสอบว่าได้เลือก Portfolio ที่ต้องการเพิ่มผลงานไว้แล้ว
4. กดปุ่ม Import
5. หากนำเข้า Portfolio Item เพียง 1 รายการ ระบบจะแสดงข้อมูลในแบบฟอร์มเพื่อให้ตรวจสอบและกดบันทึก
6. หากนำเข้าหลายรายการ ระบบจะเพิ่มข้อมูลลงใน Portfolio ที่เลือกไว้โดยอัตโนมัติ
7. ตรวจสอบว่า Portfolio Item ที่นำเข้าแสดงผลใน Portfolio เรียบร้อยแล้ว
